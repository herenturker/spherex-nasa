# Hosted image assets

Original uploaded/generated image assets used by the deployed Floot app are ordinarily served from `/_cdn/static/` and are distinct from `static/` source items. Where available they are copied here for preservation; check CDN URLs in the project source if moving to another Floot workspace. Font files and user secrets are intentionally excluded.

NASA, NASA Space Apps and institution marks remain property of their owners, with separate usage conditions.
